# ⚡ QuickServe

### Local Service Booking Platform

QuickServe is a modern **service-booking web application** that connects customers with local service professionals. It provides a simple flow for discovering services, finding suitable providers, booking services, and managing bookings from dedicated customer and provider dashboards.

This project was developed as part of the **Saylani Mid Hackathon**.

## 📖 About The Project

Finding reliable local service professionals can often be difficult because customers have to search through scattered contacts, social media, or personal recommendations.

**QuickServe** provides a centralized platform where customers can:

* Discover available services
* Browse service providers
* Compare providers
* View provider details
* Check experience, location, ratings, and pricing
* Request a service
* Track their bookings

Service providers can create their own listings and manage incoming booking requests through a dedicated provider dashboard.

# ✨ Key Features

## 👤 Customer Experience

### 🔐 Authentication

QuickServe provides a complete authentication flow with:

* Customer account registration
* Provider account registration
* Login
* Role-based access
* Logout

The signup interface allows users to select whether they are joining as a **Customer** or **Provider**.

### 🔎 Browse Services

Customers can browse available service categories through the dedicated Services section.

The homepage also presents a services section with a **View All Services** option.

### 👨‍🔧 Find Providers

The Providers page allows customers to discover professionals and compare them based on relevant information.

Provider discovery includes:

* Provider name
* Skill/service
* Location
* Rating
* Experience
* Pricing
* Verification status

The page also provides search and filtering functionality.

### 🔍 Provider Search & Filters

Customers can search providers by:

* Name
* Skill

They can also filter providers by:

* 📍 Location
* ⭐ Rating

Available location filters include **Karachi, Lahore, and Islamabad**, with rating options including **4.5+** and **4+**. A reset option is also available.

Each provider has a dedicated profile page where customers can view:

* Provider information
* Location

# 📅 Service Booking

QuickServe follows a simple booking flow:

**Find a Service → Choose a Provider → Book Service → Provider Accepts → Complete & Review**

The provider profile includes a dedicated booking interface where customers can submit a service request.

---

# 📊 Customer Dashboard

Customers have a dedicated **My Bookings** dashboard.

The dashboard allows customers to:

* View their bookings
* Track service requests
* View booking statistics
* Manage their service requests
* Book a new service

If no services have been booked, an appropriate empty state is displayed.

# 🧰 Provider Experience

Service providers have their own dedicated workflow.

# 🔄 How QuickServe Works

The platform is built around a simple **4-step service journey**:

### 01 — Find a Service 🔎

Browse service categories and discover professionals.

### 02 — Book a Provider 📅

Select a provider and submit a service request with the preferred time.

### 03 — Provider Accepts 👨‍🔧

The selected professional reviews the booking request.

### 04 — Complete & Review ⭐

The service is completed and the customer can share their experience.

This workflow is directly represented in the QuickServe homepage.
